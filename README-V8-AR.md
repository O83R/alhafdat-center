# تحديث المركز V8

- البرامج القرآنية سنوية أو بحسب مدة المسار، وليست كل الدورات ثابتة.
- الدورات العلمية المتجددة لها تاريخ بداية ونهاية وفترة تسجيل مستقلة وحالات قادمة/مفتوحة/منتهية.
- صفحة المقرأة الإلكترونية ونموذج تسجيل استعراضي مستقل.
- صفحة فريق العمل توسعت لتستوعب كامل الطاقم الإداري دون نشر أسماء افتراضية.
- كل الطلبات ما تزال تجريبية وتُحذف من حقول النموذج بمجرد الإرسال؛ لا تتصل بقاعدة بيانات ولا تُنشئ طلبات.
- يلزم تطوير لوحة تحكم وقاعدة بيانات وتحديد الصلاحيات وبيانات المركز المعتمدة لتفعيل الإدارة والتسجيل الحقيقي.
