# تحديث الصفحة الرئيسية — V3

هذه نسخة تجريبية من الموقع، تستند بصريًا إلى التصميم الذي اعتمده صاحب المشروع.

## التغييرات
- صفحة رئيسية جديدة تعرض اسم المركز والشعار الفني الكبير مع تدرجات وردية وذهبية.
- بطاقات الرؤية والرسالة والقيم، البرامج، الإحصائيات، الأخبار والمشاريع.
- بقية الصفحات والتفاعلات محفوظة كما في النسخة التجريبية السابقة.
- النماذج لا تجمع أو ترسل بيانات.

## مهم
- الرسم في بداية الصفحة مقتطع من التصور التصميمي المعتمد، وليس ملف الشعار الرسمي المتجهي. ينبغي استبداله بأصل عالي الدقة عند وصوله من المركز.
- الرؤية، الأخبار، المشاريع، صورها وتواريخها عناصر تجريبية أو ناقصة: لا تُنشر كأخبار أو بيانات حقيقية.
- للتحديث على GitHub Pages: احفظ نسخة من الملفات الحالية، ثم ارفع محتويات هذا المجلد إلى جذر المستودع. انتظر نجاح Workflow الخاص بالنشر.
