# مركز الحافظات النموذجي — V4 (للمراجعة)

## ما تم
- اعتماد التوجه البصري الهادئ للواجهة الرئيسية، وإزالة الزخارف المزدحمة والفوانيس.
- توحيد تصميم الصفحات الداخلية عبر خلفيات متدرجة خفيفة، عناوين، زخرفة هندسية بسيطة، بطاقات وأزرار ونماذج.
- إضافة خط Noor بصيغتي Regular وBold من الملفات المرفقة من صاحب المشروع.
- الحفاظ على بنية SPA الحالية وروابطها ونماذجها التجريبية.

## المعاينة
افتح `index.html` في المتصفح بعد فك ضغط الحزمة. لا حاجة لخادم أو تثبيت حزم.

## ملاحظات
- النسخة تجريبية؛ لا تنشر نماذج البيانات قبل ربطها بالأنظمة الخلفية والتحقق من النصوص الرسمية.
- ينبغي التأكد من ترخيص نشر ملفات الخط مع الموقع قبل النشر العام.
- لم يُرفع أي شيء إلى GitHub أو الموقع الحي.
